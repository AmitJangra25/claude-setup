# Go-to repos

Reference material to reach for on a specific project — not standing rules,
just a shortlist so relevant options aren't forgotten. Not exhaustive.

- **APIs** — [public-apis/public-apis](https://github.com/public-apis/public-apis) (free public APIs, browse before building a custom integration) · [googleapis/googleapis](https://github.com/googleapis/googleapis) (canonical Google API definitions)
- **Docs → Markdown** — [microsoft/markitdown](https://github.com/microsoft/markitdown) (convert PDFs/Office docs to Markdown before feeding them into Claude)
- **MCP servers** — [modelcontextprotocol/servers](https://github.com/modelcontextprotocol/servers) (official reference servers) · [punkpeye/awesome-mcp-servers](https://github.com/punkpeye/awesome-mcp-servers) (broader community directory)
- **UI components** — [shadcn-ui/ui](https://github.com/shadcn-ui/ui) (accessible Tailwind/Radix components — already used in Voice Flow)
- **Building with Claude** — [anthropics/claude-cookbooks](https://github.com/anthropics/claude-cookbooks) (official prompting/tool-use/agent examples) · [anthropics/claude-agent-sdk-typescript](https://github.com/anthropics/claude-agent-sdk-typescript) (official TS SDK for custom agents)
