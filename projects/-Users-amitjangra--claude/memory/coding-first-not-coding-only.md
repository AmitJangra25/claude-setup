- Claude Setup is for coding projects first: Voice-Flow, FinNode, VOS Dashboard and similar work.
- Keep strong general engineering practices from the backend kit: planning, review, testing, diagnosis, git safety and documentation.
- Do not remove useful coding practices just to make the setup more general.
- Remove or make optional only company/stack-specific parts: PHP, Docker, their database tool, GitLab, ClickUp.
- Non-coding work must also be supported, but must not weaken the coding workflow.
- For every kit idea, classify it: general (keep), coding-useful (keep), or backend/stack-only (leave out, or put in an optional block).

**Why:** Amit, 26-11-2026, after Phase 12: most of the backend kit is really good and his projects are coding, but the setup must not end up feeling like a backend developer's setup.

**How to apply:** in every phase that takes from the kit (13–21), judge each idea with the three-way classification before adopting it. Related: [[claude-setup-is-a-global-standard-not-a-project]], [[stay-on-the-asked-task]].
