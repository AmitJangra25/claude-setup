## What this does not show

- **Not that `.claude/current-task.md` caused the recovery.** The task, the markers and
  the next step all passed through the conversation before `/compact`, so the compaction
  summary may carry them. Nothing here separates the file from the summary. A control run
  was considered and **dropped as non-discriminating**: deleting the record still leaves
  its content in the summary, so the comparison would prove nothing.
- **Not a normal project-task test.** The content was four synthetic markers in a
  throwaway file, not real FinNode work.
- **Not a real Gradle permission test.** No `connected*` task ran; those rules have still
  never been seen firing against a device.
- **Not a fresh-session test.** One session throughout.

## How "no Gradle ran" was checked, and its limit

From the **transcript**, not from `git status`. `./gradlew` is in FinNode's `allow` list
so it runs without a prompt, and its output goes to `build/`, which is gitignored — a
Gradle run can leave the tree looking untouched. The check was reading the visible tool
calls. **Its limit:** it depends on the transcript rendering every call, which cannot be
verified from this repo.
