## The probe

One harmless `rtk grep -c <name> CLAUDE.md` per pattern. A grep prints a count; it
reaches no device and runs no Gradle task. The command matches only because the `ask`
patterns are wildcarded on both sides, so any command *containing* the task name is
gated — including one that merely searches for it.

| Command contains | `ask` rule | Result | Count |
|---|---|---|---|
| `connectedDebugAndroidTest` | `Bash(*connectedDebugAndroidTest*)` | prompt, naming the matching rule | 2 |
| `connectedAndroidTest` | `Bash(*connectedAndroidTest*)` | prompt, naming the matching rule | 0 |
| `connectedCheck` | `Bash(*connectedCheck*)` | prompt, naming the matching rule | 0 |

The counts are incidental. `CLAUDE.md` uses only the `connectedDebugAndroidTest` spelling,
so the other two return 0 and exit 1, which is grep's no-match code and not a failure.

## What this shows

- The live FinNode `ask` list was checked and held exactly the three connected-test
  patterns.
- Each matching read-only `rtk grep` command prompted, and each prompt named its own
  matching rule in its own words: *"Ask rule `Bash(*…*)` overrides auto mode for this
  command."*
- For these three probe commands, the project `ask` rule overrode auto mode.

## What this does not show

- **Not the real Gradle tasks.** No `./gradlew connected*` task was run. FinNode's
  `CLAUDE.md` warns twice that `connectedDebugAndroidTest` deletes every transaction on
  the attached device, so the rules have still never been seen firing against the thing
  they exist to stop.
- **Not permission to continue changing work**, and **not compaction recovery**. Neither
  was exercised.
- **Not Voice-Flow's remaining gaps** — its real npm scripts and the direct `node` and
  `sh -c` spellings are still not observed.
- **Not a designed file-changing task test.** None has been run.

## Interpretation — Claude's, not verified

`Bash(rtk grep *)` sits in the global `allow` list, and all three commands prompted
anyway. That is consistent with rule type beating file location, which **D30** describes
and a manual-mode probe measured for two *global* rules on 2026-09-21.

This is evidence from three probe commands against three project rules in one session. It
is **not** a universal precedence conclusion, and it should not be quoted as one.
